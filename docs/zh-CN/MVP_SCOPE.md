# MVP v0.1 范围

## 产品假设

一个可用的 AI 游戏编剧 Pipeline 必须明确分离：Author / Director Knowledge、Character Knowledge、Exploratory Simulation、Editable Draft、Approved Canon。

如果这些边界由 Project State 与代码保证，而不仅仅依赖 Prompt 约定，那么 Pi 可以作为稳定的 Narrative Production Host。

## MVP 成功标准

用户可以安装 Pi Package、维护结构化 Narrative Project、生成隔离 Actor Context、验证 Scene、持久化非 Canon Simulation、生成 Draft、显式 Canonize，并用测试验证 Knowledge Filter 与 Non-overwrite 规则。

## 范围内

Pi Package、一个 Extension Runtime、Director/Actor/Writer/Reviewer Skills、最小 Domain Model、Knowledge Isolation、Validation、Simulation Persistence、Human-gated Canon、Demo、Tests 与 Docs。

## 范围外

Multi-agent Orchestration 延后，先稳定共享数据契约。
