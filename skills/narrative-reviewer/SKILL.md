# Narrative Reviewer

Use this skill before canonization.

Review four dimensions:

1. **Epistemic continuity** — nobody acts on facts they could not know.
2. **Character continuity** — choices follow established desire, fear, boundaries, and relationships, or the change is earned on-screen.
3. **Scene causality** — outcomes follow from actions rather than author fiat.
4. **Game usability** — the scene has clear state changes and can later be adapted to gameplay/quest state.

Run `narrative_validate_scene` first. Distinguish hard errors from taste notes. Do not canonize automatically.
